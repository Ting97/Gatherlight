Flow A · One-sentence five-domain capture

timeline domain
User's casual notemoment-feed input: text / voice / image (entries can carry audio and multiple images)
Preprocessingvoice → ASR transcription (ffmpeg transcode fallback); image → vision model
LLM five-domain recognitionper-domain applicable + confidence · tolerant zod contracts (non-numeric confidence coerced to 0.5 / string-boolean phantoms rejected) · rule-engine fallback (mood / time inference)
confidence ≥ 0.6
Auto-written into the domain
confidence < 0.6
Pending queuerecorded only after human confirmation (editable)

Downstream consumptionmoment feed · calendar conflict detection · budget alerts · favor ledger · AI weekly reports & periodic reviews

Flow B · Domain assistant Q&A

chat domain
User askssix assistants: Global / Goals / Schedule / People / Finance / Fitness
chat agentdomain system prompt (hot-reloadable from admin) + conversation history + user vocabulary
Tool calls (OpenAI tools protocol)20 read-only tools query the database directly: 15 query_* + 5 get_* → answers grounded in real data
Trust boundarythe AI never writes business data directly — creations / edits become proposal cards (e.g. propose_fitness_plan), written only after user confirmation, with an audit log entry

Gatherlight Business Design

Personal life OS: one-sentence capture → five-domain recognition → domain assistants · all data stays on your own server

🕒Time & To-dostime
Day / week / month / year calendar views · conflict detection · today's action list · subtask breakdown · daily repeats
🎯Goal Spacesgoal

Core business flow · from one sentence to review

low-confidence results are never auto-recorded
A casual one-linermoment-feed input: text · voice (ASR transcription) · image (vision recognition)
AI five-domain recognitioneach domain judged independently for "applicable + confidence"; nothing is force-classified
confidence ≥ 0.6 · auto-recorded
Written directly into the modulesusers can correct anything at any time within each module
confidence < 0.6 · needs confirmation
Pending queueenters the books only after human confirmation (content editable)
Landed in five domains + people
🕒 Time blocks 📋 To-dos 💰 Transactions 😊 Mood 🍽 Diet 👥 Social favors
Automatic follow-upscalendar conflict detection · budget overrun alerts · favor ledger · birthday / anniversary reminders (lunar supported)
Periodic reviewsAI weekly finance report · goal & time reviews (result caching + generation quotas)
