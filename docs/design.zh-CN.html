Monorepo 模块结构

模块职责规模关键内容
apps/web前端（静态导出）210 文件 · 2.74 万行16 个页面路由 · 50+ 组件（日历四视图 / 待办看板 / 关系轨道图 / 动态流）· 中英 i18n · PWA
apps/api服务端（API + 静态托管）183 文件 · 2.25 万行src/server 11 域拆分 · 95 条路由 · middleware 鉴权
packages/aiAI 内核（纯包，无运行时依赖）23 文件 · 0.59 万行zod 五域契约（容错）· glm.ts 模型接入（SDK / legacy 双传输）· 提示词 · 时间推断 · 心情规则兜底 · Jev 备链路
packages/shared跨端类型与纯函数23 文件 · 0.27 万行北京时区日期 · 农历 · CSV 导入 · 关系图谱 · 提醒 · Bearer / CORS · API 客户端
packages/db数据库层69 个迁移手写 SQL + 迁移 runner（tsx 执行，无 ORM）
packages/design-tokens设计令牌生成器令牌源 + tokens:verify 漂移校验（CI 卡点）
scripts/qa演示与审计7 个脚本六域演示数据 seed · i18n 审计

依赖方向：apps → packages（ai / shared / db 互不反向依赖）；AI 逻辑集中在纯包，便于 node:test 直接覆盖。

链路 A · 一句话五域录入

timeline 域
用户随口记录动态流输入：文字 / 语音 / 图片（entry 可附音频与多图）
预处理语音 → ASR 转写（ffmpeg 转码兜底）；图片 → 视觉模型
LLM 五域识别每域独立判定 applicable + confidence · zod 契约容错（非数字置信度降 0.5 / 拒绝字符串布尔幻影）· 规则引擎兜底（心情 / 时间推断）
置信度 ≥ 0.6
自动写入对应域
置信度 < 0.6
待确认队列人工确认（可修改）后才入账
五域落库🕒 日程时间块 · 📋 待办 · 💰 收支流水 · 😊 心情 · 🍽 饮食（另识别人际往来）
联动与消费动态流 Feed · 日历冲突检测 · 预算预警 · 人情往来账 · AI 周报与周期复盘

链路 B · 分域助手问答

chat 域
用户提问六域助手：全局 / 目标 / 日程 / 人际 / 财务 / 健身
chat agent域内系统提示词（管理端可热更）+ 会话历史 + 用户词汇
工具调用（OpenAI tools 协议）20 个只读工具直查数据库：query_* 15 个 + get_* 5 个 → 基于真实数据生成回答
信任边界AI 永不直接写业务数据 —— 需创建 / 修改时产出提案卡（如 propose_fitness_plan），用户确认后才写入并记录审计日志

CI 流水线

安全与治理

内置约束
